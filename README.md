# Yoyo Reading Assistant

Yoyo Reading Assistant is a Chrome/Edge MV3 extension built with WXT, Vue 3, and TypeScript.

## Development

    pnpm install
    pnpm dev

## Verification

    pnpm typecheck
    pnpm lint
    pnpm test
    pnpm build

Load the Chrome MV3 build from `.output/chrome-mv3` in Chrome or Edge developer mode.
